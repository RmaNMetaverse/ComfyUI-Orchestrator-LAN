Where the finished files are gathered

A LAN share such as \\FILESERVER\ComfyOutputs, or any folder on this computer. Every image, video and audio file is downloaded here as soon as the machine that made it finishes.

Sub-folders

Tokens: {run_id} {machine} {workflow} {filename} {stem} {ext} {task} {seed} {node} {kind} {job} {date}. With several workflows in one run, a workflow layout keeps their outputs apart.

Reuse this setup

Save the workflow, overrides and output settings as a job file so a script or a scheduled task can run it with cf run <file>.
